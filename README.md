# DSH Chess Game

单文件网页双人国际象棋——两个人在同一台电脑上用鼠标轮流对战，零依赖、零安装，浏览器打开 `index.html` 即玩。

## 玩法

- 白方先行，点一下自己的棋子（显示可走格圆点），再点一下目标格落子
- 红圈表示可吃子；被将军的王红圈高亮提示

## 完整规则支持

- 王车易位（含王被将军、经过格受攻击、车已动过等全部条件检查）
- 吃过路兵（en passant）
- 兵升变（后/车/象/马四选一弹窗）
- 将杀（Checkmate）、逼和（Stalemate）
- 50 回合规则、子力不足和棋
- 悔棋、新对局、SAN 标准记谱

## 正确性验证

走法引擎通过标准 perft 校验（走法枚举数与国际象棋公认参考值完全一致）：
